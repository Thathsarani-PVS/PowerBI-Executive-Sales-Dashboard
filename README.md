# 📊 Executive Sales & Profit Analytics Dashboard (Power BI)

## 📌 Project Overview
This interactive Power BI dashboard provides a comprehensive analysis of executive sales performance, overall business profitability, and product trends. It enables stakeholders to track core revenue drivers and evaluate regional market success.

## 🔑 Key Features & Visual Insights
- **KPI Summary Cards:** Real-time visibility into Total Sales Revenue, Overall Profit, and Total Units Sold.
- **Sales Trends Over Time:** Line chart displaying sales distribution across time periods.
- **Geographic Performance:** Clustered bar chart identifying top-performing target countries.
- **Product Profitability:** Column chart analyzing individual product margins.
- **Dynamic Segment Slicer:** Interactive filter allowing user-driven analysis by customer sector (Government, Enterprise, Small Business, etc.).

- **Tool:** Power BI Desktop
- **Data Source:** Financial Sample Dataset (Power BI)
